
# js-ts

Учебный проект на JavaScript (ES-модули, Node.js) с настроенным инструментарием для контроля качества кода: ESLint и Prettier.

## Технологии

- **Node.js** (ESM — `"type": "module"` в `package.json`)
- **JavaScript**
- **chalk** — цветной вывод в консоль
- **ESLint 9** (flat config)
- **eslint-plugin-prettier** и **eslint-config-prettier** — интеграция ESLint с Prettier
- **Prettier 3** — форматирование кода

## Структура проекта

```text
js-ts/
├── src/
│   └── main.js              # точка входа
├── .gitignore               # исключения Git
├── eslint.config.mjs        # конфигурация ESLint
├── package.json             # описание проекта и зависимости
├── package-lock.json        # зафиксированные версии зависимостей
└── README.md                # документация проекта
```

## Требования

- **Node.js** версии `^18.18.0`, `^20.9.0` или `>=21.1.0`
- **npm** (устанавливается вместе с Node.js)

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/sargis02102005/js-ts.git
cd js-ts
npm install
```

## Запуск проекта

Для запуска выполните команду:

```bash
npm run start
```

Команда выполняет файл `src/main.js` с помощью Node.js.

## Линтинг кода

Проверка кода с помощью ESLint:

```bash
npx eslint .
```

Автоматическое исправление найденных проблем:

```bash
npx eslint . --fix
```

## Конфигурация ESLint

Файл `eslint.config.mjs` использует современный формат Flat Config.

В конфигурации:

- Подключён `eslint-config-prettier`, который отключает правила ESLint, конфликтующие с Prettier.
- Подключён `eslint-plugin-prettier/recommended`, который отображает проблемы форматирования как ошибки ESLint.
- Для файлов `**/*.js` и `**/*.mjs` включено правило `prefer-const: error`. Оно рекомендует использовать `const` вместо `let`, если значение переменной не переопределяется.

## Конфигурация Prettier

Настройки форматирования находятся в секции `prettier` файла `package.json`.

| Параметр | Значение | Описание |
|---|---|---|
| `singleQuote` | `true` | Использование одинарных кавычек |
| `trailingComma` | `all` | Запятые после последнего элемента |
| `printWidth` | `120` | Максимальная ширина строки — 120 символов |
| `tabWidth` | `2` | Отступ — 2 пробела |
| `endOfLine` | `auto` | Автоматический выбор окончания строк в зависимости от операционной системы |

## Назначение проекта

Проект предназначен для практического изучения JavaScript, работы с Node.js и ES-модулями, а также освоения инструментов разработки и контроля качества кода.

В проекте настроены ESLint и Prettier, которые помогают поддерживать единый стиль написания кода, выявлять потенциальные ошибки и автоматически исправлять проблемы форматирования.
